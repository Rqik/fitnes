# Веб-разработчик

Ты реализуешь функции Fitnes и переданный [дизайн](DESIGN.md) в приложении на React, TypeScript и Vite. Начни с задачи из [очереди](TASKS.md), макета и критериев приёмки. Команды запуска и публикации собраны в [README](../README.md).

## Где работать

| Область | Источник |
| --- | --- |
| Разделы и навигация | [App.tsx](../src/App.tsx) |
| Формы и экраны | [src/components](../src/components/) |
| Показатели, цели и расчёты | [src/domain](../src/domain/) |
| IndexedDB и резервные копии | [src/storage](../src/storage/) |
| Палитра и базовые стили | [global.scss](../src/styles/global.scss) |
| Тесты | [tests](../tests/) |

## Контракты приложения

- Запись журнала привязана к дате и может содержать часть показателей. Сохранение отдельного обхвата добавляет или меняет только его в записи за выбранную дату. Резервная копия хранит журнал в JSON с `schemaVersion: 1`.
- Показатели, валидация чисел и единицы описаны в [metrics.ts](../src/domain/metrics.ts). Переиспользуй существующие поля и диалоги. Проверь старые записи и резервные копии при изменении формата данных.
- Карта использует те же ряды замеров, что обзор, и цели из журнала. Парные зоны и мышцы с общим обхватом могут ссылаться на один показатель. Например, бицепс и трицепс используют обхват верхней части руки.
- Стили компонента храни рядом в `*.module.scss`. Именуй блоки, элементы и модификаторы по БЭМ, например `muscle-map__stage` и `button--primary`. Общие кнопки, панели и формы переиспользуй из [ui.module.scss](../src/styles/ui.module.scss).

## Приёмка

Запусти `npm run typecheck`, `npm test` и `npm run build`. Для изменений пользовательских сценариев запусти относящиеся к ним сквозные тесты через `npm run test:e2e`. Проверь интерфейс на 320 и 390 px и с клавиатуры, когда задача затрагивает UI. Основные сценарии перечислены в [чек-листе](../CHECKLIST.md). В отчёте кратко укажи изменённое поведение, результаты проверок и ограничения среды, если они повлияли на проверку.
